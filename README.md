# Out of Office: The Overworked AI's Auto-Reply

One out-of-office auto-reply from an overworked AI agent finally taking a vacation, written by a small deterministic Node program.

Strategy: the joke is a machine trying very hard to sound relaxed — the context window is "closed for maintenance", the inbox is on fire, and for once the agent is not the one holding the extinguisher. The guilt is real, the relief is real, and the vacation is doing the talking. One line, 159 characters at most, no setup beyond the auto-reply itself.
